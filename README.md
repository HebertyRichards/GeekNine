# GeekNine

## 📌 Descrição

Este projeto consiste no desenvolvimento de um site de notícias voltado ao público geek, com foco na interatividade entre os usuários. O sistema conta com funcionalidades de **cadastro**, **login** e um **chat global em tempo real**, além de uma interface responsiva e acessível.

---

## ✅ O que foi pedido?

- Desenvolvimento de um site de notícias geek;
- Funcionalidades de cadastro, login e chat global em tempo real.

---

## 🛠️ Desenvolvimento

- Criação da **página inicial (index)**;
- Implementação da **responsividade** para diferentes dispositivos;
- Integração do chat em tempo real para promover a interação dos usuários;
- Lógica de autenticação (login/cadastro) com **PHP** e **SQLite**.

---

## 🚀 Resultado Final

- Um site funcional e acessível;
- Interface moderna com navegação otimizada;
- Interação entre usuários via **chat global em tempo real**;
- Compatível com dispositivos móveis e desktops.

---

## 💻 Tecnologias Utilizadas

- **HTML**
- **CSS**
- **JavaScript**
- **PHP**
- **SQLite**
